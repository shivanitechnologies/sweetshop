# sweetshop

SweetBliss — Traditional Mithai & Handcrafted Snacks Store.

A responsive, festive, and modern e-commerce storefront designed for authentic Indian sweet shops, traditional savory snack brands, and luxury festive/wedding gifting hampers.

---

## 🌟 Key Features

* **Warm, Festive Royal Aesthetic**: Crafted with rich Burgundy (`#7B263A`), Heritage Gold (`#D6A653`), and warm Ivory Cream (`#FFF8F0`) tones.
* **Auspicious Festival Calendar & Pre-Orders (`festivals.html`)**:
  * Live countdown timer for upcoming festivals.
  * Curated celebration packages for Diwali, Holi, Raksha Bandhan, Ganesh Chaturthi, and Makar Sankranti.
  * Fresh small-batch simmering guarantee and complimentary brass diya / roli-chawal packaging.
* **Wedding Shagun & Invitation Bhaji Studio (`weddings.html`)**:
  * Live interactive monogram customizer (real-time couple initials preview with gold foil embossing).
  * Velvet trunk, Rajasthani brass platter, and Banarasi potli keepsake box collections.
  * ₹299 Doorstep Tasting Sample Box (sample 5 signature delicacies before placing bulk orders).
* **Pan-India Cold-Chain Order Tracking (`track-order.html`)**:
  * Visual 4-stage tracking (Order Confirmed → Simmered in Brass Kadhais → Aroma-Lock Vacuum Sealed → Cold-Chain Air Cargo Dispatch).
  * 6-digit Pincode serviceability checker (Metro same-day 3-4h express vs Pan-India 24-48h air delivery).
  * Complete shelf-life, storage, and savoring preservation guide.
* **Interactive Mithai Box Builder**: Custom 4-in-1 sweet box configurator with live calculation and 10% curated discount.
* **Frictionless Shopping & Cart Drawer**: Slide-out cart with subtotal, free delivery threshold tracker, and direct WhatsApp / Order Enquiry checkout without forced login.
* **Accessibility & Localization**:
  * RTL (Right-to-Left) mode toggle.
  * Dark mode / Light mode toggle.
  * Zero horizontal overflow on mobile screens down to 320px.
